🛂 About the Project
This project performs an Exploratory Data Analysis (EDA) of US visa applications to:

Identify trends in visa issuance and denials.
Highlight factors affecting visa outcomes (e.g., employer type, job category, and salary).
Provide actionable insights for policy evaluation and process improvement.
🔍 Key Features
Data cleaning and preprocessing for large datasets.
Exploratory analysis to understand approval and denial trends.
Visualizations to highlight patterns by year, employer, and industry.
Automated scripts for consistent analysis workflows.

📂 Dataset
The dataset includes US visa application records.
Source: US Department of Labor / Kaggle.
Features include:
Case Status: Approved, Denied, Withdrawn, etc.
Job Title, Employer Name
Wages Offered, Work Location
Visa Class, Year
📈 Analysis Workflow
Data Loading: Import the dataset and perform an initial inspection.
Data Cleaning:
Handle missing or inconsistent values.
Standardize categorical data.
Exploratory Analysis:
Analyze visa approval rates by year and job category.
Study the distribution of wages across industries.
Visualization:
Heatmaps to show correlations.
Bar and pie charts for categorical data.
Line charts for trends over time.
